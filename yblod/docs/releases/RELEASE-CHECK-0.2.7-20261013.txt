YBLOD 0.2.7 validation

Build source: 947ee7dcff4f513f0cafac949c8cad3d2bbfc10b (PR #16 on top of 0.2.6)
LibreELEC upstream base, FFmpeg, libplacebo, kernel, Kodi, native engine, engine
defaults and shaders are unchanged from 0.2.6 (byte-identical, hashes below).

Changes since 0.2.6
- skin.estuary.yblod 4.1.0+yblod.17 -> 4.1.0+yblod.20 (both editions).
- service.webostv 0.8.3 -> 0.8.8 (LG edition; carries Remote Bridge 0.6.3).
Both release zips match the pinned PKG_SHA256. The skin still requires only xbmc.gui;
its LG, Denon and Sonos controls are shown only when those add-ons are present (LG) or
report a connection (Denon, Sonos), so the standard edition shows none of them.

Images
Both: skin.estuary.yblod 4.1.0+yblod.20 in /usr/share/kodi/addons, optional in the
add-on manifest, appliance.xml default skin.estuary.yblod, /usr/lib/yblod/skin-move with
kodi.service.d/30-yblod-skin.conf. LG: service.webostv 0.8.8 and
repository.dangerouslaser 1.0.1, optional.

Testing
These add-on versions run on Ollie's Kodi container, the Petunia VM and the N150 (from
the dangerouslaser repository, as reported in PR #16), on 0.2.6 Kodi, which this
release keeps unchanged. The 0.2.7 images themselves were not installed before
publishing; the image checks above are from the built SYSTEM files. Playback, skin
default and skin move were validated on 0.2.6 with the same Kodi, engine and kernel.
