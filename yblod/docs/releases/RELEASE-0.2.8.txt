YBLOD 0.2.8 updates the pre-installed Estuary YBLOD skin and LG webOS TV Control add-on, and makes two small Kodi changes for pointer remotes.

What changed
- Estuary YBLOD 4.1.0+yblod.21 (both editions): panels on the playback controls for the LG TV, Sonos and Denon that stay open while you use them. They replace the add-ons' list dialogs, which closed and reopened after every change; toggles and volume act in place and follow changes made from other remotes. The Sonos button uses Sonos's round logo. Fixed: on the LG TV page, "Motion, quality and sound" could not be scrolled past "Cleanup: HD video". The panels only show when their add-ons are installed (LG) or connected (Denon, Sonos).
- LG edition: LG webOS TV Control 0.8.9, which provides the LG TV panel's values (motion and each picture setting) and opens one picture setting's choices from it.
- Kodi: an animated image (such as an animated mouse pointer) now plays from its first frame each time it shows, instead of carrying on from where it was hidden.
- Kodi: a skin or add-on can keep the mouse pointer on screen when a key is pressed (Window(Home).Property(MousePointerStays): "true" for every key, "nomove" for every key but the arrows), so a TV remote's pointer doesn't disappear on every button. When it is not set, keys hide the pointer as before.
- The kernel and the native engine are unchanged from 0.2.7. Both editions are built from the same source.

If you run 0.2.7
Update from your edition's channel (yblod-13.0 or yblod-lg-13.0). LG edition systems that already received these or newer add-on versions from the dangerouslaser repository keep them.

Install
Update using the .tar of your edition in /storage/.update/, or use the .img.gz for a fresh installation. Back up your settings first. See the attached validation report and SHA256SUMS.

All 0.2.2 notes and known limitations still apply: https://github.com/dangerouslaser/libreelec-yblod/releases/tag/yblod-0.2.2
