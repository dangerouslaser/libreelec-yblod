YBLOD 0.2.8 validation

Build source: 60370c55d2228e0f94ec2ebf3720e9b92d7e7210 (PRs #17 and #18 on top of 0.2.7)
LibreELEC upstream base, FFmpeg, libplacebo, kernel, Kodi source, native engine, engine
defaults and shaders are unchanged from 0.2.7.

Changes since 0.2.7
- skin.estuary.yblod 4.1.0+yblod.20 -> 4.1.0+yblod.21 (both editions).
- service.webostv 0.8.8 -> 0.8.9 (LG edition).
- Kodi patch 9993-guiimage-restart-animation-when-shown: an animated image's texture
  plays from its first frame each time the image shows.
- Kodi patch 9994-input-mouse-pointer-stays-on-keys: Window(Home).Property(MousePointerStays)
  keeps the mouse pointer up on key presses ("true": every key; "nomove": every key but
  the focus-moving ones). Unset, keys hide the pointer as before.
Both add-on release zips match the pinned PKG_SHA256. The skin still requires only
xbmc.gui; its LG, Denon and Sonos panels are shown only when those add-ons are present
(LG) or report a connection (Denon, Sonos), so the standard edition shows none of them.

Images
Both: skin.estuary.yblod 4.1.0+yblod.21 in /usr/share/kodi/addons, optional in the
add-on manifest, appliance.xml default skin.estuary.yblod, /usr/lib/yblod/skin-move with
kodi.service.d/30-yblod-skin.conf. LG: service.webostv 0.8.9 and
repository.dangerouslaser 1.0.1, optional.
Both Kodi patches are applied in the build log. Comparing every file of the 0.2.7-lg
and 0.2.8-lg SYSTEM images: apart from the two add-ons and the version strings
(/etc/issue, os-release, release, kodi/defs.pyc), only kodi.bin differs. That kodi.bin
differs in one byte, its embedded build date, from the 0.2.7-ptr1-lg test build
(0.2.7 with the same two patches).

Testing
0.2.7-ptr1-lg, with the same Kodi patches, runs on the Petunia VM. The add-on versions
run on Ollie's Kodi container, the Petunia VM and the N150 (from the dangerouslaser
repository, as reported in PR #17). The 0.2.8 images themselves were not installed
before publishing; the image checks above are from the built SYSTEM files. Playback,
skin default and skin move were validated on 0.2.6, whose engine and kernel this release
keeps.
