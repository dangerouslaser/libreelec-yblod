LibreELEC upstream base, FFmpeg, libplacebo, kernel, native engine, engine defaults and

Changes since 0.2.5
- Kodi patch 9995 (realtime passthrough, PR #13): VideoPlayerAudio no longer rules out
  passthrough for realtime streams; SyncTypeFor() uses SYNC_DISCON for passthrough and
  SYNC_RESAMPLE for decoded realtime audio; sync to display still resamples everything.
  Tested by its PR in Ollie's Kodi container (yblod-0.2.5-pt1-lg): an IPTV Simple E-AC3
  channel opens as pt-eac3 and the receiver reports Dolby Atmos - DD+.
- Kodi patch 9997 (grouplist wheel destination, PR #12): a grouplist steps each wheel
  notch from its scroll destination (new CScroller::GetDestination()), as lists do.
- skin.estuary.yblod 4.1.0+yblod.17 (the renamed skin.estuary.lg) in both editions, an
  optional system add-on and Kodi's default skin: its post_install adds the
  lookandfeel.skin default to appliance.xml at image assembly. skin.estuary.lg is no
  longer in the images.
- /usr/lib/yblod/skin-move (kodi.service.d/30-yblod-skin.conf, before Kodi starts): a
  box set to skin.estuary.lg is switched to skin.estuary.yblod and its skin settings are
  copied to the new id unless that already has its own. Replaces the LG edition's
  first-run-defaults.
- LG edition: service.webostv 0.8.3.

Images
Both: skin.estuary.yblod 4.1.0+yblod.17 in /usr/share/kodi/addons, listed optional in the
add-on manifest, appliance.xml default skin.estuary.yblod. LG: service.webostv 0.8.3 and
repository.dangerouslaser 1.0.1 optional as before. Kodi's source has patches 9995 and 9997.

N150, yblod-0.2.6-lg (this build) installed over a 0.2.6-lg test build, itself installed
over 0.2.5-lg (box already on skin.estuary.yblod)
- Kodi starts on Estuary YBLOD, now stored as the default value; add-ons enabled.
- Default skin: lookandfeel.skin reset to the old default (default="true",
  skin.estuary): Kodi starts with skin.estuary.yblod.
- Move: lookandfeel.skin set to skin.estuary.lg and Estuary YBLOD's skin settings
  removed: Kodi starts with skin.estuary.yblod, with no Kodi dialog. skin-move run on
  its own copies the settings file byte-identical (md5); after Kodi has run, all 105 old
  skin settings are present with their values, plus 3 setup flags added at start.
- P7 FEL: play, pause, resume, seeks, paused seek, Home over video, return to
  fullscreen, playback controls and stop pass with zero errors.

Limitations
The standard 0.2.6 image was not separately installed; its Kodi, skin package, engine
and kernel match the tested LG image. The N150 runs a newer, unpublished service.webostv
(0.8.5) from /storage, so the shipped 0.8.3 was not exercised there. The mouse wheel
and live passthrough changes were tested by their PRs (Petunia, Ollie's container), not
again on this image; lip-sync over long live passthrough sessions is not yet checked.
No visual TV confirmation is part of this report.
