YBLOD 0.2.4 validation

Build source: ce6415655c348bf01a0d77b0b9e5aadcab3cfc3a (PR #6)
LibreELEC upstream base, Kodi, FFmpeg, libplacebo, kernel and LG add-ons are
unchanged from 0.2.3. Only the native engine and its runtime defaults changed.

Changes since 0.2.3 (engine only, all enabled in runtime.env)
- DV_RECON_ACTIVE_ROWS=1: reconstruct only the RPU L5 active rows plus a filter
  margin (FEL/MEL, single polynomial and piecewise routes). Launch-offset window;
  reconstruction kernels unchanged.
- DV_OVERLAY_INLINE=1: the overlay pack checks the exact GUI pixel cache itself;
  the separate full-canvas GUI colour pass is removed. Falls back to the prepass
  route (logged) when a user override removes a prerequisite.
- DV_SINGLE_TABLE_CACHE=1, DV_DUAL_TABLE_CACHE=1: reshaping tables are reused
  while the RPU composer config is unchanged.

Byte-exact check (N150, installed yblod-0.2.4-lg, packaged defaults plus
DV_VERIFY_ACTIVE_ROWS=200, DV_OVERLAY_INLINE_VERIFY=200 and both table-cache
verify switches; 1917, No Country for Old Men, Deadpool, Gemini Man, Sol Levante
P8.4; each with playback controls, Home over video, navigation, return and stop)
- Active-row reconstruction: 801 frames re-run over the full frame, 0 byte
  differences in the displayed rows.
- Inline overlay pack: 971 overlay frames repacked from fresh, uncached GUI
  colours, 0 byte differences over the full 3840x2160 scanout.
- Table caches rebuilt on every hit: 0 mismatches (single 780/1 and 1247/1
  hits/misses; dual 835/1 and 203/495).
- No inline fallback, no Kodi log errors, native route active throughout.
Earlier per-feature checks: letterbox 0 differences on 9 titles incl. a forced
P8.4 window; inline overlay 750 frames incl. P8.4 4:2:2.
