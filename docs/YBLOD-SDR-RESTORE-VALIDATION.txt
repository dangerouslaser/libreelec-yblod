DV exit SDR restoration — 2026-10-10

Failure
With DV menus disabled, normal YBLOD returned from Sky Sports Main Event UHD
through the FEL clip and Gemini Man to a menu signalled as HLG. Connector 609
had HDR_OUTPUT_METADATA EOTF 3 and Colorspace 9 (BT2020_RGB), matching the TV
overlay report. The DV bridge's saved pre-DV HDR/colorimetry snapshot outlived
renderer teardown and overwrote Kodi's clearing of HDR on stop.

Change
Renderer teardown replaces only the saved HDR metadata/colorimetry restore
values with the bridge's no-HDR/default-colour values. The saved link policy,
plane properties and LUTs remain unchanged. This also covers delayed refresh
restoration, retaining the same single restore transaction. DV menu handoff
continues using DV transport values, not the saved restore values.
