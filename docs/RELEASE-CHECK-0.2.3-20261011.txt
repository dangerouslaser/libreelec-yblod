YBLOD 0.2.3 validation

Build source: 6ed23907966489b48e58cf7b06681f166fcd3752
LibreELEC upstream base is unchanged from 0.2.2. LibreELEC master had 16 newer
commits (Amlogic platform work and repository add-ons: inputstream.adaptive,
visualization.projectm, minisatip); none is part of the Generic x86-64 image.

Changes since 0.2.2
- Kodi patch 20: optional system add-ons are also updated from an installed
  third-party repository that carries a newer version (Kodi otherwise updates
  system-origin add-ons from the official repositories only).
- LG edition: skin.estuary.lg 4.1.0+lg.9, service.webostv 0.6.1. The
  repository.dangerouslaser 1.0.1 addon.xml is kept in the package because its
  published zip changes checksum on every repository publish (contents identical).
- Engine, engine defaults and shaders are byte-identical to 0.2.2.

Add-on update check (N150, 0.2.3-test1-lg: patch 20 with skin 4.1.0+lg.7 and
service.webostv 0.5.3 pre-installed)
With addons.updatemode=0 (official repositories only, Kodi's default) and a forced
repository check, Kodi installed skin.estuary.lg 4.1.0+lg.9 and service.webostv
0.6.1 from the dangerouslaser repository into /storage/.kodi/addons; both enabled.
The same check on 0.2.2-lg, without patch 20, installed nothing.

Playback check (N150, yblod-0.2.3-lg): P7 FEL play, pause, resume, seeks, Home over
video, playback controls and stop pass with zero errors; the three LG add-ons are
enabled at the shipped versions.
